# Site personnel

Mon site personnel regroupant mon CV, outils, ressources : https://acheruel.github.io

Page statique (HTML, CSS, JS, sans étape de compilation) publiée par GitHub Pages depuis la branche `main`.

Les petits outils sont hébergés directement dans ce site, dans `outils/` : Photo Rapporto, PDFo Comparo,
PDFo Converto et MarkDownO, avec son banc d'essai d'outils PDF vers Markdown (un dossier et un README par outil). Le code et les bibliothèques communs sont
dans `outils/commun/` et `outils/vendor/`.
