À vérifier avant un usage LLM

  • Chaque valeur est-elle dans la bonne ligne et sous la bonne unité ?
  • Les cellules fusionnées gardent-elles leur relation ?
  • La figure est-elle présente, avec sa légende et ses cotes ?
  • Le texte des images est-il reconnu ?
  • Les colonnes se lisent-elles dans le bon ordre ?

Une image exportée n’est pas une description. Pour un LLM textuel, il faut de l’OCR et, selon le dessin, une analyse visuelle contrôlée. Gardez toujours la source.

Ce que ce prototype permet de décider

Conserver MarkItDown pour les formats Office ; évaluer Docling et PyMuPDF pour les PDF complexes. Le moteur PDFo reste le point de comparaison local, rapide et sans modèle.

Parsade / Granite Docling ↗ utilise un modèle visuel WebGPU distinct du pipeline Docling standard. Ses performances ne sont pas déduites de nos essais CPU. Une sortie externe peut être importée dans l’un des panneaux ; elle sera indiquée comme non chronométrée.

PDFo Converto conserve ses fonctions pendant l’évaluation. Le regroupement PDF → Markdown dans MarkDownO pourra suivre une fois le moteur et les exports validés.
